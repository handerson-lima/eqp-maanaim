# Maanaim --- BMAD Design Pack

Este pacote deve acompanhar o PRD v1.1 no repositório.

## Arquivos

1.  `DESIGN-SYSTEM.md` --- tokens e linguagem visual.
2.  `UX-LAYOUT-SPEC.md` --- regras de layout e responsividade.
3.  `COMPONENT-CATALOG.md` --- catálogo conceitual de componentes
    Flutter.
4.  `SCREEN-SPECS.md` --- especificação das telas.
5.  `DESIGN-RULES-FOR-AGENTS.md` --- instruções normativas para agents
    BMAD.
6.  `references/maanaim-ui-reference.png` --- referência visual
    principal.

## Uso sugerido no BMAD

Os agents de UX/Architecture/Stories/Dev devem ler, nesta ordem:
`PRD v1.1 → DESIGN-RULES-FOR-AGENTS → DESIGN-SYSTEM → UX-LAYOUT-SPEC → SCREEN-SPECS → COMPONENT-CATALOG`.

A imagem deve ser consultada para validação visual, não como substituta
das regras escritas.
